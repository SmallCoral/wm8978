# STM32F407 + WM8978 USB 声卡

这是一个基于 STM32F407VET6 和 WM8978 的 USB 全双工音频硬件工程，目标功能为
USB 立体声播放、单声道麦克风采集、耳机输出和 BTL 扬声器输出。仓库目前只包含
KiCad 硬件工程，不包含 STM32 固件。

## 主要电路

### USB 与电源

- USB-C CC1、CC2 分别使用 5.1 kΩ 下拉，接口工作在 USB 设备/UFP 模式。
- D+ 从 USB-C A6/B6 经 D1 和 R53 接 STM32 PA12。
- D− 从 USB-C A7/B7 经 D2 和 R54 接 STM32 PA11。
- D1、D2 为 `PESD5V0U1BA` 双向低电容 TVS，用于 USB 数据线 ESD 保护。
- 3.3 V 稳压器使用 `TLV1117LV33DCYR`，不要在未核对输出电容稳定性要求时替换
  为泛化 AMS1117 器件。

### STM32F407

- HSE：8 MHz 晶体 X3，C68/C69 为 18 pF；量产前应根据实际晶体和寄生电容复核。
- I2S2：PC6/MCLK、PB13/BCLK、PB12/LRCLK、PC3/DACDAT。
- WM8978 控制总线：PD6/SCLK、PD7/SDIN。
- BOOT0 由 R50 下拉，并可通过 SW5 拉高。
- PB2/BOOT1 由 R69（10 kΩ）下拉，避免启动模式悬空。
- SWD 接口用于固件下载和调试。

### 模拟电源与地

- 所有 STM32 VDD 接 3V3，所有 VSS 接 GND。
- R51 是 `VSSA—0 Ω—GND` 单点连接。VSSA 直接接系统地属于正常用法；保留
  0 Ω 电阻便于测量，或在实测噪声需要时替换为磁珠。
- R52 是 `3V3—0 Ω—VDDA` 单点连接，同样可在噪声测试后评估是否改用磁珠。
- VREF+ 与 VDDA 同网，并在 MCU 引脚附近去耦。

### WM8978 与音频接口

- WM8978 使用两线控制模式：CSB 接地，MODE 使用 10 kΩ 下拉。
- C88、C90、C92 为 100 nF 高频去耦。
- C79、C80 为 1 µF 麦克风输入耦合电容，C83 为 4.7 µF VMID 去耦。
- C86、C87 为 220 µF/16 V 耳机输出隔直电容，正极朝向 WM8978 输出端。
- ROUT1/LOUT1 接 3.5 mm 耳机输出。
- ROUT2/LOUT2 构成 BTL 扬声器输出；SPK_P、SPK_N 均不可接地。

## PCB 布局与布线要求

- D1/D2 应紧贴 USB-C 数据引脚，ESD 泄放到地的路径必须短而宽。
- R53/R54 应靠近 STM32 PA12/PA11，并保持 USB D+/D− 等长、同层、少过孔。
- X3、C68、C69 应紧贴 MCU，晶振回路下方不要穿过高速信号或分割地平面。
- 每个 100 nF 去耦电容必须靠近对应电源脚，优先经过电容再连接电源面，并配置
  短地过孔。
- WM8978 模拟输入输出应远离 USB、晶振和 I2S 时钟，耳机回流不得穿过数字回流区。
- SPK_P/SPK_N 应成组布线，不能把任意一路当作单端输出或连接到 GND。
- USB 供电时扬声器满功率会显著增加 VBUS 电流，固件应限制初始音量并软启动。

## 已完成的关键修正

- 删除 STM32 去耦区域中误将 3V3 与 GND 短接的导线。
- 修正 PCB 上 STM32 VSS 10、27、74、99 的 GND 网络。
- 增加 PB2/BOOT1 的 R69 下拉，并同步 PCB 焊盘网络。
- 将 C88 修正为 100 nF，并清理电容值与符号料号的明显冲突。
- 将 D1、D2 移到 USB-C 附近；其拓扑保持为数据线对地并联 TVS。

## 制板前检查清单

1. 在 KiCad 中执行完整 ERC，逐项处理错误和未确认警告。
2. 从正式原理图更新 PCB，确认没有元件、网络或封装被意外重置。
3. 完成板框、布局、差分走线、电源与地平面、安装孔和丝印。
4. 执行 DRC，并检查 USB 差分阻抗、回流连续性、去耦回路和模拟地回流。
5. 核对 BOM 中的电容耐压、封装、晶体负载电容和 USB-C 连接器料号。
6. 导出并复核 Gerber、钻孔、坐标和装配文件。
7. 首板按 5 V、3.3 V、VDDA、HSE、USB 枚举、I2S 时钟和音频输出的顺序上电验证。
